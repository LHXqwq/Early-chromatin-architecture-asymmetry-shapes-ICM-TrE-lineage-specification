# Early chromatin architecture asymmetry shapes the molecular basis of ICM or TrE lineage specification in porcine preimplantation embryos

This repository contains the key analysis code used in the study:

**"Early chromatin architecture asymmetry shapes the molecular basis of ICM or TrE lineage specification in porcine preimplantation embryos".**

In this study, we applied single-cell Hi-C (scHi-C) and single-cell RNA sequencing (scRNA-seq) to investigate chromatin architecture and transcriptional dynamics during early porcine embryonic development. Using both in vitro fertilized (IVF) and parthenogenetic (PA) embryos, we characterized cell-to-cell heterogeneity in 3D genome organization and explored its associations with developmental potential and lineage-specific gene expression.

The code provided in this repository supports the key analyses presented in the study.
